# 在客服软件里同步 ima 知识库

1. 通过 [ima 官方配置页](https://ima.qq.com/agent-interface) 获取 ima 的 Client ID 和 API Key。
2. 打开企业微信智能客服工作台，在「资料库 → 同步 ima」填入凭证，点击「读取我的知识库」，按名称选择共享库，再测试连接。接口使用的库编号与网页链接里的数字编号不同。
3. 在 ima 中把按游戏整理的 TXT 问答放在知识库根目录。文件名为「游戏名 客服问答.txt」，第一行写「游戏名｜客服知识库」，正文每条用「问：」和「答：」各占一行，使用 UTF-8。
4. 点击「保存并同步」。软件为这一个 ima 库创建独立档案，以后同步时更新该档案里的同名资料。同步完后，从资料库档案菜单切换，并在「试问一句」检查命中资料。

客服软件从本地档案检索，再用已配置的模型生成客服回复。默认业务提示词用于生成简短回复并保留版本、区服和渠道条件。可以开启「软件运行时自动同步」并设置间隔，默认 15 分钟。同步面板显示上次结果，失败后保留已有资料。

凭证可以在同步窗口临时输入，也可以由本机提供 `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY` 环境变量，或按 ima 官方格式放在用户目录的 `.config/ima/client_id` 和 `.config/ima/api_key`。这两项凭证只用于 ima 接口。
