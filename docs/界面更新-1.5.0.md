# 1.5.2 独立桌面工作区

解压整个文件夹后，双击 `启动.bat`。新版界面直接显示在独立桌面窗口中，无需打开浏览器，也没有地址栏或标签页。再次启动会唤回已运行的窗口。

窗口支持最小化、最大化、调整尺寸、文件导入与导出。关闭窗口会退出程序并停止消息采集与自动回复；资料操作仍在进行时会提示稍后再关闭。也可以在「设置 → 应用」中重启或退出。程序启动后默认暂停，需要主动开始。

保留已有业务逻辑、消息队列和资料库。本地向量模型在首次检索时加载。界面使用 Windows WebView2 运行时（Windows 11 通常已内置）；不需要安装 Python 或 Node。旧桌面窗口仅在独立窗口启动失败时作为备用入口显示。

## 页面与操作

| 页面 | 功能 |
| --- | --- |
| 待人工 / 需要关注 | 查看原话、检查草稿、编辑发送、忽略；保留发送失败及结果待核实状态 |
| 全部消息 / 已回复 | 搜索、筛选、完整消息详情、CSV 导出、清空当前窗口列表 |
| 数据看板 | 日期范围、接待趋势、处理分类、原话样例、常转人工问题、CSV 导出 |
| 资料库 | 全库搜索、分页、问答编辑、撤销、删除、文件导入、重建索引、档案管理 |
| AI 整理 | 先读取资料并确认范围，再整理；核对原文、编辑和勾选后才写入 |
| 常见转人工问题 | 查看全量排行、标记已补、补充资料、清空统计 |
| 提示词 | 六类提示词、必需占位符校验、恢复默认、即时保存 |
| 学到的 | 开关语气学习、预览实际注入内容、删除/屏蔽、采纳或拒绝业务事实 |
| 试问一句 | 使用当前资料库验证检索和匹配度，不发送客户消息 |
| 设置 | 模型接口、模型列表、连接测试、接入通道、微信客服凭据、重启与退出 |

页面使用统一的深色分区、字体、间距、按钮与表单状态。页面切换保留编辑草稿；刷新网页会重新读取本机数据，未保存内容需先保存。多个窗口同时修改资料时会提示重新读取，避免覆盖新内容。

## 首次配置与升级

- 分发包保留业务资料、上传源文件、提示词与窗口标定。
- 密钥、客户会话、待人工队列、运行日志、个人学习记录不包含在分发包中。首次使用请到“设置”填写自己的接口；原程序目录中的数据未被改动。
- 密钥输入框不回显已存密钥。留空表示保留原值；勾选清除才删除。更换模型服务地址后，请填写对应服务的密钥。
- 接入通道变更需要重启；提示词和模型设置保存后立即生效。
- 重建索引会根据源文件重新生成；仅手动添加、没有对应源文件的资料不会保留。通常“导入文件”后无需再重建。
- 原有发送判断、人工确认、消息队列与回复规则沿用原流程。结果待核实等关键确认仍可能显示桌面确认框。

详细业务配置见同目录的 `使用说明-详细.md`。界面方法与第三方字体、图标的授权见 `UI-开源许可.txt`。
