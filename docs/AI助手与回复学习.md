# AI 助手与回复学习

从左侧「AI 助手」进入，可以查询模型设置、提示词、知识条目和学习内容，也可以让助手起草修改，或生成带上下文的客服测试回复。

修改提示词和资料时，助手先展示当前内容和变更预览。点击「应用变更」后保存。提示词和资料的本次变更可以点击「撤销这次变更」，对象已有后续修改时需要重新核对。

## 手动回复后的学习

在软件内编辑回复并成功发送后，新版工作区会显示「学习这条回复」。可以分别选择将完整问答加入资料库、学习语气习惯和保存口吻样本。直接确认发送 AI 草稿时，也可以核对并保存完整问答。

学习结果保存到当前资料库档案。点击「稍后处理」后，可在「学习记录」继续确认。先保存语气后，可以再次打开该条记录补充保存问答。学习关闭时可在「学习记录」开启，或从「已回复」主动分析单条记录。

「已回复」新增学习状态。点击记录可以查看客户原话、实际回复、已学习类别，并进入对应资料。「已学习语气，问答未入库」表示只保存了措辞。条目后续修改或删除时，状态会显示「入库条目已变更或删除」。旧历史没有保存学习关联时显示「尚无学习记录」。

学习跟随软件确认成功的发送记录。在企业微信客户端直接输入的回复，可以到资料库手动补充问答。

## 历史复核稿

在「学习记录 → 导入历史复核稿」选择 JSON 复核文件。每条保留游戏、原始行号、复核依据和需要确认的条件。核对当前版本、区服和活动后，可编辑完整问题与答案并采纳。处理历史保留实际发布的问答和条目关联。

## 外部 AI 接入

在「AI 助手 → 外部 AI 接入」复制 MCP 配置，添加到支持 MCP 的客户端。软件运行时，脚本通过本机工作区会话连接。工具支持读取、检索、回复预览、生成修改预览、应用和撤销。配置中使用随包 Python 和 scripts/assistant_mcp.py 的绝对路径。

模型使用软件「设置」中保存的 OpenAI 兼容接口。外部工具读到的设置隐藏密钥。
